# Lucide toolbar icons

`calendar-arrow-down.svg` uses the official `calendar-arrow-down` path data from
Lucide 1.28.0. Only its display size (18 × 18) and stroke color (`#b5bbc6`) are
adapted to the app's dark interface.

`refresh-cw.svg` is the official `refresh-cw` icon from the same Lucide version,
with the same display size and stroke color adaptations.

- Icon: https://lucide.dev/icons/calendar-arrow-down
- Source: https://raw.githubusercontent.com/lucide-icons/lucide/1.28.0/icons/calendar-arrow-down.svg
- Refresh icon: https://lucide.dev/icons/refresh-cw
- Refresh source: https://raw.githubusercontent.com/lucide-icons/lucide/1.28.0/icons/refresh-cw.svg
- License: `LICENSE.lucide` (ISC license and upstream notices)

Bundled locally for offline use.
